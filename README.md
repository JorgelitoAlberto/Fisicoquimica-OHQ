# Gu-a-Fisicoqu-mica-OHQ
Este libro es una guía de entrenamiento para la Olimpiada Hondureña de Química (OHQ). Escrito por mi persona, cubre gases ideales y reales, termoquímica, propiedades coligativas, electrólisis y cinética. Incluye teoría clara, fórmulas, trucos de examen, errores comunes y problemas resueltos diseñados para competir con éxito.
