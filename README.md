# Físicoquímica Olímpica

Material de preparación para el área de **Fisicoquímica** de la Olimpiada Hondureña de Química (OHQ).

**Autor:** Jorge Alberto Banegas Beltrand — Medallista en Olimpiadas de Matemáticas, Química, Física y Astrofísica. Comayagua, Comayagua, Honduras.

## Contenido

1. Ley del gas ideal (Boyle, Charles, Gay-Lussac, Avogadro, `PV=nRT`)
2. Termoquímica (entalpía, Ley de Hess, entropía, energía de Gibbs)
3. Gases reales (ecuación de Van der Waals)
4. Propiedades coligativas (descenso crioscópico, Ley de Raoult)
5. Leyes de Faraday (electrólisis, celdas electrolíticas)
6. Cinética química (órdenes de reacción, leyes integradas)

Cada capítulo incluye conceptos clave, fórmulas destacadas, tips olímpicos, errores comunes, problemas resueltos paso a paso y problemas propuestos con respuesta.

## Compilar

Requiere **XeLaTeX** (usa `polyglossia`, `fontspec`, `mhchem`, `tikz`, `pgfplots`, `tcolorbox`).

```bash
xelatex Fisicoquimica_Olimpica.tex
xelatex Fisicoquimica_Olimpica.tex   # segunda pasada, para el índice y las referencias
```

El PDF resultante (`Fisicoquimica_Olimpica.pdf`) tendrá 33 páginas.
